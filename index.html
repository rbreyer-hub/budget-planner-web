FAQ

The honest questions.

Where is my data stored?

In your browser's local storage — nowhere else. Nothing is uploaded, nothing leaves your device. If you clear your browser data, you lose your budgets, so use Backup All periodically to download a JSON copy.

Can I use this on multiple devices?

Yes, but it doesn't auto-sync. On device A, click Backup All to download a JSON file. On device B, click Restore Backup and pick that file. Repeat whenever you make changes you want to carry over.

How do multiple users share a browser?

Each browser stores its own data, so if two people share a computer with separate browser profiles, they each get their own budgets. Within one browser, the tabs (e.g. “My Budget”, “Joint Budget”) let one user track several budgets side-by-side.

What's the “In balance” checkbox on incidentals?

Use it for incidentals already reflected in your current bank balance. The item is recorded for tracking but skipped from balance projections, so it doesn't get subtracted twice.

Is the code open source?

Yes — it's hosted on GitHub Pages from a public repository. Fork it, audit it, or run your own copy.
